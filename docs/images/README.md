# README screenshots

These images show fictional data from the local demo. They contain no real Superset sessions.

To refresh them:

1. Run `bun run demo` and open `http://127.0.0.1:4401/?still=1`.
2. Leave the project filter on All sessions and press `F` to fit the scene.
3. Capture the page as `fleet-overview.png`.
4. Open the agent panel, select Recipe search, and capture `fleet-conversation.png`.

The demo fixes the sample activity, clock, weather, and random seed. `still=1` pauses animation;
the Resume button lets you explore the moving scene. Capture the browser page itself, without
browser chrome or other desktop windows. Keep labels readable and use PNG for the pixel art.

Use the demo for new public images too. A real fleet can show private prompts, code, and paths.
